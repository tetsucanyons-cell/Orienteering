# GVカヌー予約確認サイト (PWA)

Googleスプレッドシート「Kanu-yoyuaku-List」から予約スケジュールおよびガイドの出勤情報を直接取得し、iPhoneのブラウザでリアルタイムに確認できるWebアプリケーションです。

Pythonサーバーを使わず、HTML/JSのみでスプレッドシートから直接データを取得する構成になっているため、**一度インターネット上に無料公開すれば、PCを一切起動することなく、iPhoneの操作だけでいつでも最新の予約状況を確認できます。**

---

## 📱 iPhoneでの初期設定と使い方

### 方法 1: ローカルWi-Fi環境で使う場合 (簡易方法)
PCと同じWi-Fiに接続している間だけiPhoneからアクセスする方法です。

1. **PC側での起動**:
   - `start.bat` をダブルクリックして実行します。
   - 黒い画面（コマンドプロンプト）が開き、PCのIPアドレス（例：`192.168.1.xxx`）が表示されます。
   - ※この画面を開いている間だけサーバーが動作します。

2. **iPhone側での接続**:
   - iPhoneのSafariを開きます。
   - PCの画面に表示されたIPアドレスを元に、以下のようにURLを入力してアクセスします。
     ```
     http://[PCのIPアドレス]:5000
     ```
     *(例: `http://192.168.1.100:5000`)*

---

### 方法 2: PCを完全に不要にする（インターネットに無料公開する）※超推奨！
このアプリ（HTML/JSのみ）を無料のホスティングサービスにアップロードすることで、**PCの電源が切れていても、外出先からでも、iPhoneからいつでもリアルタイムに確認できるようになります。**

最も簡単で安全な公開方法として「**Vercel（ヴァーセル）**」または「**Netlify（ネットリファイ）**」の利用をお勧めします。

#### ☁️ ドラッグ＆ドロップで公開する手順（例: Netlify の場合）
1. ブラウザで [Netlify](https://www.netlify.com/) にアクセスし、無料アカウントを作成します。
2. ログイン後、管理画面の「Sites」メニューを開きます。
3. 画面下部にある **「Drag and drop your site folder here」**（ここにサイトのフォルダをドラッグ＆ドロップしてください）というエリアを探します。
4. 本プロジェクト内にある **`static` フォルダごと**、そのエリアにドラッグ＆ドロップします。
5. 数秒でアップロードが完了し、専用のURL（例：`https://xxxxx.netlify.app`）が自動で発行されます。
6. 以降は、そのURLにiPhoneからアクセスするだけで動作します（PCのバッチ起動は不要です）。

## 📲 iPhoneのホーム画面にアプリアイコンを追加する (PWA化)

ホーム画面にショートカットを配置することで、アドレスバーが非表示になり、まるで本物のスマホアプリのように全画面で起動できるようになります。

1. **Safariでウェブサイトを開く**:
   上記「方法1」または「方法2」のURLをiPhoneの **Safari** で開きます。
2. **共有メニューを開く**:
   画面下部の中央にある「共有」ボタン（四角から矢印が飛び出しているアイコン）をタップします。
3. **ホーム画面に追加**:
   メニューを下にスクロールし、**「ホーム画面に追加」** をタップします。
4. **追加の完了**:
   名前（デフォルトで「GV予約確認」）を確認し、右上の「追加」をタップします。
5. **起動**:
   ホーム画面にカヌーのアイコンが表示されます。タップすると全画面でアプリのように起動します。

## 🛠️ 技術的な仕様
- **データ取得方法**: Google SheetsのCSVエクスポート機能を利用し、JavaScript（Fetch API）で直接データをダウンロード・パースします。
- **リアルタイム性**: アプリの起動時、および画面右上にある「更新」ボタンをタップした際に、キャッシュを無視して最新の情報をGoogleスプレッドシートから再取得します。
- **対応列位置**: 
  - `日付` / `開始時間` / `学校名` / `生徒` / `教員`
  - 出席ガイド欄：スプレッドシートの **U列（21列目）** から順に以下のガイドが配置されている前提です。
    `哲さん` / `英さん` / `羽山さん` / `Rez` / `バボちゃん` / `五島` / `FW（どんどん）` / `FW（ゆげっち）`
  - メモ欄：スプレッドシートの最終列を「メモ」としてパースします。
